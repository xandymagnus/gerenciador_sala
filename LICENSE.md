# Projeto acadêmico

Este projeto foi desenvolvido para fins acadêmicos por:

* **Alexandre Magno**
* **Felipe Lopes**
* **Otávio Peralta**

O projeto foi desenvolvido no contexto acadêmico da **Rede Anhanguera**,
com o objetivo de aplicar conhecimentos de desenvolvimento web, banco de
dados e engenharia de software.

A disponibilização do código sob a licença MIT tem como objetivo permitir
estudo, aprendizado, colaboração e desenvolvimento pela comunidade.

A utilização de marcas ou elementos de identidade visual da instituição
não implica que o projeto seja propriedade da Rede Anhanguera nem que os
autores sejam titulares dessas marcas.
